# Naming Guidelines

Use these names consistently:

| Context | Canonical name |
| --- | --- |
| Project | Musashi Dojo Agent |
| Repository slug | `musashi-dojo-agent` |
| Agent | Niten |
| Full agent presentation | Niten — the Musashi Dojo Ninja Agent |
| Operational role | Dojo Node Operator |
| Local workspace | `.musashi/` |
| Network environment | Musashi Dojo |
| Informal community nickname | Musashi Ninja |

Use **Niten** in normal conversation, status messages, and command explanations. Use the full presentation in README material, first-run onboarding, visual identity, public descriptions, announcements, and documentation headers.

“Musashi Ninja” is informal only and must not replace Niten as the canonical agent name.
